# 🌳 Baumsicherheitsbeurteilung

Digitales SVLFG-Formular zur einsatzbezogenen Gefährdungsermittlung und Baumsicherheitsbeurteilung – kostenlos, offline nutzbar, direkt im Browser.

**[→ App öffnen](https://ropesconnectingpeople.github.io/GBU)**

---

## Was kann die App?

- ✅ Digitales Ausfüllen des SVLFG-Formulars (STD, Stand Sept. 2019)
- 📸 Fotos zur Beurteilung hinzufügen
- 📄 PDF-Export – sauber formatiert, unterschriftsbereit
- 📤 Direktes Teilen per WhatsApp, Mail, etc.
- 💾 Beurteilungen speichern und wieder öffnen
- 📵 Funktioniert komplett offline
- 📱 Installierbar auf iPhone, Android und Desktop

## Installation auf dem Handy

**iPhone (Safari):**
Seite öffnen → Teilen-Button → „Zum Home-Bildschirm" → Hinzufügen

**Android (Chrome):**
Seite öffnen → Drei-Punkte-Menü → „App installieren"

## Formulargrundlage

Basiert auf dem offiziellen Formular des Sicherheitstechnischen Dienstes der SVLFG:
„Einsatzbezogene Gefährdungsermittlung / Baumsicherheitsbeurteilung" (Stand September 2019)
